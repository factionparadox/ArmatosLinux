# Lexicon Armatum

Every Armatos term in one place.

## The Empire

| Term | Meaning |
|---|---|
| **Armatos Linux** | The distro. *Armatos* means "the armed ones" |
| **Imperator** | You, the user. The prompt is `imperator@roma` |
| **roma** | Default hostname |
| **AUC** | *Ab urbe condita*, the release dating. 2026 is MMDCCLXXIX |
| **`linux-legio`** | The Armatos kernel |
| **Salve / Vale** | Boot greeting / farewell |
| **porta** | The lock screen, the city gate |
| **lex** | A law: policy files such as APT pins. *Lex I* pins systemd at 259 |

## Tools

| Term | Meaning |
|---|---|
| **`cursus`** | APT wrapper, after the *cursus publicus*, the imperial road and post |
| **`damnatio`** | Snapshots and rollback, after *damnatio memoriae* |
| **`colonia`** | Installer: founding a colony on the disk |
| **`census`** | System report |
| **Forum** | App store; categories are *tabernae* (stalls) |
| **Senatus** | Settings app |
| **`vesta-temple`** | Discord installer. The Vestals kept the flame burning round the clock |

## Repositories

| Term | Meaning |
|---|---|
| **italia** | Core Armatos packages |
| **provinciae** | Extra packages |
| **barbaricum** | Non-free firmware and blobs |
| **peregrina** | Flatpak apps, goods from foreigners who ignore Armatos's laws |
| **tributum** | Updates |

## Desktop

| Term | Meaning |
|---|---|
| **Titulus** | The Quickshell bar, an inscription band |
| **Colosseum** | Window overview (Super+Tab) |
| **I–IX** | Workspaces |
| **acta** | Daily terminal greeting, after the *acta diurna* |
| **edicta** | Notifications |
| **Marmor** | The overall Armatos look |
| **Tribunus** | GTK theme |
| **Cloaca Maxima** | Trash |
| **frescoes** | Screenshots |
| **tabula** | Clipboard |
| **castra / cohortes** | Flavour names for services (systemd itself is untouched) |

## Guardians and oracles

| Term | Meaning |
|---|---|
| **Praetorian Guard** | AppArmor (enforce) + ClamAV |
| **`centurion`** | Security AI: commands the Guard, reports to the Imperator, never acts alone |
| **`sibylla`** | General assistant, after the Cumaean Sibyl |
| **`haruspex`** | Reads the entrails, meaning your logs |
| **`augur`** | Quick answers |
| **Lar** | Household companion |

## Otium (wellbeing)

| Term | Meaning |
|---|---|
| **Otium** | Restful leisure, the wellbeing layer |
| **lucerna** | Evening night light, warmed to oil-lamp colour |
| **Thermae** | Ambience and meditation |
| **Meditations** | Marcus Aurelius, used for guided reflection |
